## 这个仓库想证明什么

四个项目，都围绕同一个问题：**这个结论经得起检验吗？**

课程作业通常停在"算出了一个看起来合理的数字"。这四个项目继续往下走，走到真正
决定这个数字有没有意义的那一步——预测到底有没有打赢最朴素的基准、所谓的"市场
联动"换一个识别假设还剩下多少、两个本该对得上的数据文件到底有没有真的连接上。

下面四个核心结论里有两个是**否证结果**，而这恰好是我最希望被提问的部分。

每个项目都能从干净的仓库跑起来，自己重新生成图表和数据表。其中两个项目在每次
运行时都会把结果和存档的参考值逐个数值比对，一旦有偏差就**直接报错中止**。

## 项目

### 1 · [股票时间序列预测](projects/01-equity-time-series-forecasting/)
`statsmodels` · `ARMA/ARIMA` · `固定起点样本外检验` · `每次运行校验 252 个数值`

仅用训练集的 BIC 选出 MA(2)，在完全未被触碰的 20 天留出样本上比"零收益率"预测
的 RMSE 好 **0.29%**——但 Ljung–Box 在滞后 20 阶**拒绝**残差无自相关，ARCH-LM
也拒绝方差恒定（*p* = 4e-09）。项目的设计目的就是让这两个事实同时可见：单个窗口上
0.29% 的优势，并不是一个可以拿去用的模型。

### 2 · [沪港市场联动](projects/02-shanghai-hongkong-market-linkages/)
`VAR / VECM` · `Johansen` · `格兰杰检验` · `每次运行校验 334 个数值`

上证冲击看起来能解释恒生指数 10 步预测误差方差的 **32.4%**——直到把 Cholesky
排序反过来，同一个量变成 **0.35%**。数据、模型、样本完全一样，只换了识别假设。
同时 VAR(7) 在两个市场的 MAE 上都输给零收益率基准，两个方向的格兰杰检验都不显著。

### 3 · [中国新能源汽车转型 2015–2025](projects/03-china-nev-industry-analytics/)
`pandas` · `matplotlib` · `7 张整理数据表` · `16 张中英文图表`

十一年间新能源新车渗透率从 **1.3% 升到 47.9%**。真正让叙事复杂起来的发现是：
充电设施增速超过了车辆保有量，但几乎完全靠**私人桩**（公共桩占比从 48% 降到 23%）；
电池路线反转向磷酸铁锂（40% → **81%**）；插电混动反而**夺回**份额（17% → **36%**）。
所有分母口径、定义变更和情景假设都有记录，包括与官方总量相差 0.3 GWh 的说明。

### 4 · [共享单车交互可视化](projects/04-bike-sharing-interactive-visualization/)
`Plotly` · `Pyecharts` · `17,379 条观测` · [在线图表](https://jiayuyan117.github.io/academic-portfolio/projects/04-bike-sharing-interactive-visualization/charts/01_sunburst.html)

UCI 共享单车数据集的两个文件把日期分别存成 `2011/1/1` 和 `2011-01-01`，所以最自然
的那个连接**在 731 天里一天都没对上**——建立在它上面的任何"小时汇总等于日汇总"
的校验都会通过，因为它在拿空值和空值比较。正确解析后，两个文件确实完全一致。
四张交互图，每一张都写明了每个视觉通道编码的是什么。

## 可复现性

| 项目 | 自我校验 | 命令 |
| --- | --- | --- |
| 01 股票预测 | 11 张表 / 252 个数值，`rtol=1e-6` | `python run_analysis.py` |
| 02 市场联动 | 8 张表 / 334 个数值，`rtol=1e-6` | `python run_analysis.py` |
| 03 新能源汽车 | — | `python src/nev_visualization.py && python src/build_figures_en.py` |
| 04 共享单车 | README 数字直接读取 `findings.json` | `python src/build_charts.py` |

项目 01 和 02 交付的是**校验器**而不只是运行脚本：它会核对每个输入文件的 SHA-256
是否与 `provenance.json` 一致，清空 notebook 所有输出后从零重跑，任何单元格报错
即失败，然后把重新生成的每个数值与存档参考值比对。库版本的静默变化会表现为构建
失败，而不是一个悄悄变了的结论。

每个项目用自己的 `requirements.txt` 锁定依赖版本。Python 3.12。

```bash
git clone https://github.com/jiayuyan117/academic-portfolio.git
cd academic-portfolio/projects/01-equity-time-series-forecasting
pip install -r requirements.txt
python run_analysis.py
```

## 这些项目体现的能力

**计量经济学与预测** — ARMA/ARIMA、VAR/VECM、单位根与协整检验、格兰杰因果、
脉冲响应与方差分解、残差与 ARCH 诊断、对预先设定基准的固定起点样本外评估。

**数据工程与数据质量** — 输入文件哈希校验、连接完整性检查、日期与单位归一化、
独立来源之间的交叉核对、确定性的端到端流水线。

**可视化** — Matplotlib 做印刷级静态图，Plotly 与 Pyecharts 做交互；显式说明每个
视觉通道的编码；每张图都标注数据来源、分母口径和已知局限。

**研究表达** — 把"测量到的""估算的""仍然是假设的"三类内容分开陈述；中英文双语交付。

四个项目全部源于我本人的本科课程作业。每个项目的 `source_materials/` 目录保留了
未经修改的原始课程提交物和数据集，可以直接对照查看从作业到作品集版本的演进过程。

敏感性与稳健性分析、以及全部解释都来自我本人。凡是属于我的估算而非公开统计数字的
内容——最明显的是新能源汽车减碳情景——都在图表上直接标注。

本仓库中没有任何结论被表述得比证据所能支持的更确定。模型失效的地方，失效本身就是
发现。
