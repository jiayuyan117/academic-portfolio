# 数据来源说明 & 代码运行说明

> 课程：广东工业大学《大数据可视化原理与实践》课程设计
> 主题：**中国新能源汽车产业发展与绿色低碳转型——基于数据可视化的分析**
> 分工：数据采集 + 代码实现 + 图表输出（本目录交付物）
> 数据截止：2025 年 12 月（部分为 2026 年 1 月发布的年度统计公报）

> **当前审核状态：已整合根目录 docs/NEV_SOURCE_AUDIT.md（2026-10-21）的查证结果。** 21 个观测标为 `verified_external`，93 个课程整理观测、2 个候选引文观测仍未核验，另有 1 个 `assumption`。政府原站、政府转载、媒体报道由 `source.evidence_type` 区分。此次实施不重复网络查证；证据摘要来自审计记录，不伪作发布者逐字引文。最新计算以派生 CSV 和自动摘要为准。

## 一、怎么运行代码（3 步）

```
1. 确认已安装 Python 及 matplotlib / pandas / numpy
2. 在项目根目录执行：python src/nev_visualization.py
   英文图单独执行：python src/build_figures_en.py
3. 运行完成后自动生成：
      data\    7 个 CSV 数据文件（报告附表）
      charts\  8 张 PNG 图表（300 dpi，可直接插入 Word）
      charts_en\ 8 张英文 PNG（300 dpi）
```

- 独立输入在 `data/source/`：六张观测 CSV、一张假设参数 CSV。原脚本硬编码数组已移出。
- `data/source/provenance.json` 的 `records` 使用 `record_columns` 指定的六列：数据集、字段、年份、原值、状态、来源 ID。117 条记录覆盖 116 个观测值和一个跨年参数；参数年份为 `null`，适用年份在字段说明中列明。
- `compiled_from_coursework` 与 `needs_verification` 都不代表已核验。`verified_external` 必须结合来源证据类型阅读，不能把媒体转述说成原始统计表核验。`assumption` 单独用于作者情景参数。
- 修改数值须同步 CSV 和 provenance；已核验值须有精确 URL、发布日期、证据类型及审计中的逐值摘要、定位。审计日期与出处在 provenance 顶层记录；未提供的原文引句和研究者姓名不补造。
- 两套脚本均经 `src/data_pipeline.py` 读取输入、验证并导出七张派生表。所有跨表匹配按年份键执行，不依赖数组尾部位置。全程可离线复现。
- 执行 `python src/data_pipeline.py --check-outputs` 校验 schema、年份唯一性与覆盖、逐值来源记录及导出算术一致性；执行 `python -m unittest discover -s tests -v` 运行回归测试。
- `python src/data_pipeline.py --require-verified` 要求所有观测有外部证据，显式假设除外；历史观测尚未全核实，当前应失败。普通验证通过仅表示结构和计算一致。
- `data/analysis_summary.json` 为重建时自动求值的英文结论摘要；中文摘要由中文脚本打印。Word/PPT 应引用本次重建图，并同步待核实声明。
- 中文乱码处理：脚本已自动按操作系统选择字体（Windows→微软雅黑，macOS→苹方，Linux→文泉驿）。
- CSV 采用 `utf-8-sig` 编码，用 Excel 直接双击打开不会乱码。

### 数据 7｜作者假设的减碳情景

- 公式：`年度情景值（亿吨）= 年末新能源汽车保有量（万辆）× 系数（吨/辆年）÷ 10000`。累计为各年度情景值之和。
- 系数 **1.5 吨 CO₂ /（辆·年）** 保留在 `data/source/assumptions.csv`，独立标为 `assumption`，不作为等待外部核验的统计观测。ICCT 的欧洲乘用车生命周期研究不能支持中国全车型的这一年减碳系数，不再以其背书。
- 年末保有量替代了全年车辆暴露量，未计入行驶里程、电网、制造排放、车辆寿命及纯电/插混使用差异。不能当作实测减排或生命周期评估。
- 年度与累计输出保留六位小数，先以完整精度求和再输出；图中文字按显示精度格式化。准确数值由 `data/analysis_summary.json` 和第七张派生表输出。
- 不使用官方全球减排数字作为本项目情景的验证结论。

## 四、报告表述与商业含义

1. 数字摘要从脚本和自动生成的英文 JSON 读取，注明“部分观测已按证据核实，其余历史观测待核实”。倍数明确写“期末为期初的倍数”。
2. 销量与占比描述样本变化，不能推断“政策驱动转市场驱动”或全球排名。
3. 车桩比只能描述同一统计口径下的总量关系，不能跨 2025 断点宣传连续增长。补能选址还需要地域、功率、开放权限、故障率和利用率。
4. 电池结构可用于提出供应链敞口问题，不能仅凭份额变化证明成本、安全或技术优劣。插混应同时报告期初/期末和末年同比占比变化，避免隐去中间回落。
5. 出口规模可帮助筛选后续研究问题；利润判断还需地区、价格、关税、成本和渠道资料。
6. 减碳图不构成已实现环境绩效。现存 Office 文件均为历史课程版本，当前结果以 README 和更新图表为准，清单见 README 的 ARCHIVE 说明。
