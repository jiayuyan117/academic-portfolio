# 意图

- 场合和受众：面向美国、香港、新加坡数据科学、商业分析、信息管理、可持续发展与相关交叉专业的研究生申请作品集。
- 讲完要让招生委员会看到：申请人能够保留课程整理输入、明确外部证据缺口，完成数据治理、指标构建、可视化表达与谨慎解释，并理解模型假设与边界。
- 页数：中文与英文各 16 页，强调项目方法、分析判断、可复现性与反思。
- 必讲：研究问题、数据架构、数据质量、关键发现、绿色低碳估算、代码工程化、局限与下一步。
- 不讲：把课程作业包装成商业产品，不夸大因果结论，不把估算值写成官方统计，不把候选链接称为已核验来源。
- 当前状态：现存 Office 文件为历史课程版本，不在此次重制；当前结果以 README 与更新图表为准。下列提纲供理解研究问题，不能替代逐值证据等级。
