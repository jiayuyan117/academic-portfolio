    Core Engineering & Verification Design

    Data Integrity

    Bidirectional Structural Invariants

    Every employee record in the AVL tree must belong to exactly one department set, and every ID in any department set must resolve to an AVL node whose department() matches. verify() checks strict key bounds, cached node heights, balance factors in {-1, 0, +1}, bijection of memberships, and count(0) == n.

    Value Semantics

    Immutable Records & Exact Monetary Types

    Employees are modeled as Java 17 record Employee(int id, String name, int department, long salaryCents). Storing salaries in integer cents and aggregating department payrolls via BigInteger in subtreeSalaryCents() eliminates floating-point rounding drift and 64-bit overflow.

    Algorithmic Efficiency

    Pruned Range Search & In-Place Transfers

    Transferring an employee between departments locates the AVL node in a single O(log n) search and swaps the immutable record reference without altering keys or tree topology. idRange(minId, maxId) prunes subtrees outside the target interval in O(log n + k) time.

    Adversarial Testing

    Reference Oracle & Fault Injection

    JUnit 5 tests pair the implementation against a java.util.TreeMap oracle across 50,000 ascending/descending keys and 5,000 seeded random operations, plus reflective corruption of heights, balance, ordering, and membership to verify that verify() detects every violation.

    Complexity & Operational Guarantees

    Operation Time Complexity Auxiliary Working Space Key Invariant / Design Note
    find(id) O(log n) worst-case O(1) iterative Guaranteed logarithmic depth via AVL balancing
    add(emp) / remove(id) O(log n) AVL + expected O(1) set O(log n) recursion stack Single or double rotation restores |bf| ≤ 1; successor replacement preserves dept
    transfer(id, dept) O(log n) lookup + expected O(1) set O(1) Replaces immutable Employee record in-place without tree rotation
    idRange(minId, maxId) O(log n + k) pruned traversal O(k) result + O(log n) stack Skips left/right subtrees outside [minId, maxId]
    count(dept) / subtreeSalaryCents(dept) O(s) / O(s + m log n) O(s) explicit ArrayDeque Iterative traversal handles 20,000-deep hierarchies without stack overflow
    verify() Expected O(n + d) O(n + d) diagnostic maps Validates BST bounds, AVL height/balance, and exact membership bijection

    Evidence Boundary

    Scope & Honest Limitations. The Java implementation uses the standard library; executing its tests requires JUnit 5 and a JDK (Maven is the documented build route). The illustrations above are not test results. This is a single-threaded, in-memory teaching system without persistence, access control or production payroll validation.
