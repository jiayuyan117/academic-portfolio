Project 07 · Java coursework

Workforce System in Java

An in-memory information-system exercise that keeps a department tree and an employee search index consistent as records are added, transferred, and removed.

English README · 中文 README · Source and tests

What can be inspected

Structures
Department tree · AVL employee index · membership sets
Records
Immutable employee data · integer salary cents · ordered snapshots
Checks
Height, balance, ordering, membership and count invariants
Tests
JUnit 5 · TreeMap reference model · reproducible random operations

Evidence boundary

The implementation and tests are present in this repository and can be run with Maven. The system is a single-threaded teaching example; it does not claim persistence, authorization, payroll processing or production HR readiness.

Run it

mvn clean test
java -cp target/classes Workforce
