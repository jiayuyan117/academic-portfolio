# 07 · Java 人员与部门管理系统

**作者：闫佳玉 / Jiayu Yan。原始课程作品由本人独立完成。**

**本科课程作品 · 数据结构与信息系统**

本项目用部门树和自平衡 AVL 员工索引表示一个组织。新增、转岗和删除员工时，
两种结构必须继续描述同一组人员。项目重点是把数据结构不变量写清楚并用测试
反复检查，而不是把内存中的教学系统描述成生产级人力资源产品。

## 项目展示的内容

- AVL 树插入、删除、缓存高度以及单旋和双旋；
- 不可变员工记录，工资以非负 `long` 整数分存储；
- 部门成员集合、部门子树计数、`BigInteger` 子树精确薪资汇总（`subtreeSalaryCents`）、`O(log n + k)` 剪枝 ID 区间查询（`idRange`）和按员工 ID 排序的不可变快照；
- 包含区间端点的工资查询；
- `verify()` 检查 ID 顺序、真实高度与缓存高度、AVL 平衡、部门成员关系和总数；
- 使用独立 `TreeMap` 参考模型与可复现 `Random(42)` 序列的 JUnit 5 测试。

## 边界与限制

这是单线程、内存中的课程系统。它没有持久化、并发控制、授权、部门删除或
薪资核算；部门树本身不保证平衡，哈希表操作也不提供 AVL 索引那样的最坏情况
逐操作保证。生产使用还需要持久化、访问控制和审计历史。

项目中的“业务相关性”仅表示一致的部门归属有助于可靠的人数统计，不表示已经
产生业务效果或经过真实组织数据验证。

## 构建与测试

在本目录使用 JDK 17 或更高版本、Maven 3.8 或更高版本：

```sh
mvn clean test
java -cp target/classes Workforce
```
