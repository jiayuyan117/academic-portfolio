# 07 · 个人学习知识库 / 课程资料工作台

**Java Web 课程项目 · 信息系统 · 面向真实风险的实现复盘**

本项目源于《Java Web 应用开发》课程报告中的“课程资料管理系统”。作品集版本
把它重新表述为一个边界清楚的个人学习知识库：学生可以整理课程笔记、实验记录
和复习文件，并在需要时检索、修改和下载。

当前仓库保存的是作品集重构和证据地图，原 Java Web 源码目录并未随项目提交。
桌面报告作为原始材料被读取，但没有直接上传为主展示文件。因此，下面区分报告中
已确认的事实和当前 checkout 中可复核的内容。

## 报告确认的范围

报告确认使用 Java 21、嵌入式 Tomcat 9.0.111、Servlet 4.0、JSP/EL/JSTL、
JDBC 和 H2 2.3.232 文件数据库。确认的模块包括：

- 注册、登录、改密、退出和 7 天自动登录；
- 按用户隔离的资料记录：标题、课程、说明；
- 关键词查询、编辑和删除；
- 每条资料一个附件，支持替换和下载；
- `data/course.mv.db` 保存数据库，`data/uploads` 保存附件；
- 应用监听器、认证过滤器、CSRF 检查和资料归属校验；
- 报告记录的 66 项集成检查，以及 390px 手机宽度检查。

这些内容来自报告，不能替代缺失源码的逐行复核。

## 产品化表达

它解决的是一个有限而具体的学习资料整理流程：

```text
课程资料
  ├─ 标题 / 课程 / 说明
  ├─ 关键词检索
  ├─ 附件保存
  └─ 仅当前用户可访问
```

作品集将它作为课程范围内的信息系统案例呈现，不把它包装成生产级知识平台、
多租户服务或通用文件安全产品。

## 安全与准确性修正

- 手工拼接 `Set-Cookie` 时，必须正确编码并校验令牌值；`HttpOnly`、`SameSite`
  和条件设置 `Secure` 本身不能弥补不安全的响应头构造。
- 扩展名白名单只是文件名策略，不能证明内容类型、检测病毒或保证文件可安全预览。
- multipart 解析和大小限制错误应先于读取 CSRF 参数；否则超限上传可能被误报为
  CSRF 缺失。
- 文件写入和数据库更新属于两个资源，清理逻辑能降低普通失败后的不一致，但不构成
  进程中断或存储故障下的原子事务。
- 资料归属必须在 SQL 和下载路径解析中强制校验，隐藏字段和禁用按钮都不是权限边界。
