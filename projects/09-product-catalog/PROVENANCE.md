# Source, rights and authorship

## Topic source

The topic comes from a Java Web textbook archive named
`JavaWeb编程技术(3)程序源码(1).zip`. Its chapter05 entry names
(`addProduct.jsp`, `displayAllProduct.jsp`, `ProductDeleteServlet.java`,
`ProductQueryServlet.java`, `Product.java`) describe a JSP/Servlet/JDBC
product-management example. Chapter13 (SSH member management) was not adapted.

The textbook author, publisher, edition and redistribution license have not been
established. No textbook source contents were copied into this project.
No original archive, JAR, JSP, database configuration, password or membership
data is included. Only the general product-management topic was selected.
Repository MIT terms apply to the new implementation, not to the external
textbook materials.
